# Chess Learning and Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver child-friendly chess lessons, complete legal local play, clocks/history/replay, and a three-level in-browser Stockfish opponent.

**Architecture:** `chess.js` is the only legal-position authority. UI adapters translate its FEN/moves into board state; Stockfish is isolated behind a cancellable UCI Worker client, and learning content remains available even if the engine asset fails.

**Tech Stack:** Next.js 16.2.6, React 19.2.6, TypeScript 5.9.3, chess.js 1.4.0, Stockfish 18.0.8 lite single-threaded WASM, Web Workers, Vitest 4.1.10

## Global Constraints

- This plan starts only after foundation, Number Hunt, and Gomoku plans pass.
- Areas are Learn Pieces, Learn Rules, and Play.
- Play modes are local two-player and child versus computer; network multiplayer is excluded.
- Complete rules include legal moves, check/checkmate, castling, promotion, en passant, stalemate, repetition, and other chess.js draw states.
- Setup includes names, color/side, orientation, optional clock, and Easy/Medium/Hard computer level.
- Stockfish runs off the main thread and its URLs respect the deployed `basePath`.
- Learning and local play continue when Stockfish cannot load.
- Ship Stockfish GPL-3.0 license/source notice with pinned assets.
- Keep the 50 most recent completed Chess records.
